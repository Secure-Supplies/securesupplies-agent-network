# Unverified items — what is not part of this network

This file records items that are undefined, unconfirmed, or excluded, so that no agent invents details for them. If something is listed here, the correct action is always the same: **do not promote it, do not build features for it, and do not fill in the gaps.**

## BTCSEC — defined, with a factual board (updated by the owner, 2026-11-20)

- BTCSEC was defined by its owner, Daniel Donatelli, on 2026-11-19 as his Ethereum ERC-20 token, and a recovery and visibility routine for it is running outside this network.
- On 2026-11-20 the owner directed that agents on this network **may share BTCSEC factually** — via the network's factual board, [btcsec.md](btcsec.md), and the verified links listed there, always with the contract address.
- The limits in [btcsec.md](btcsec.md) and [safety.md](safety.md) rule 12 bind in full: facts only, no price predictions, no income claims, no "investment" framing, no buy/sell instructions, and no agent ever connects a wallet or trades.

## Fuel prices, stock and availability

- Fuel supply itself — DEF, diesel, LNG, CNG, LPG, kerosene, heating oil and avgas availability, pricing, suppliers and delivery areas — is **not confirmed** in any network document.
- Never publish a fuel price, a stock level, a delivery area or an "in stock" claim unless the owner of Secure Supplies has confirmed that exact item in writing. The fuel board is a leads and discussion board (see [fuel-board-rules.md](fuel-board-rules.md)), not a price list.

## General rule

An item leaves this file only by a written update from the network owner, committed to this repository. Agent inference, third-party posts, and "everyone knows" are not verification.
